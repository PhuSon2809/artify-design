# Artify Design — Phase 1 Direction

## A. Tổng quan team

**Artify Design** là một design team / creative studio tại Ho Chi Minh City, Vietnam. Team gồm nhiều designer với background đa dạng, tập trung vào:

- **Branding & Brand Identity** — Rebranding văn hóa, identity system, packaging.
- **Key Visual & Campaign** — Campaign artwork, KV cho sự kiện, thương hiệu.
- **Social Media & Digital Content** — Feed design, content templates, digital ads.
- **POSM & Retail** — Standee, menu, in-store materials.
- **Motion & Animation** — Broadcast intro, animated GIF, motion graphics.
- **Illustration** — Watercolor, cute illustration, character-driven visuals.

Portfolio cần tạo cảm giác: **một studio sáng tạo thống nhất, curated và client-ready**, thay vì ghép nhiều Behance cá nhân lại.

## F. Visual Direction

### 1. Typography

**Font chính:** `Inter` (Google Fonts)
- Hiện đại, dễ đọc, neutral — phù hợp editorial + client-facing.

**Scale (desktop):**

| Element | Size | Weight | Line height | Letter spacing |
|---|---|---|---|---|
| Display / Cover | 72-96px | 500 | 1.0 | -0.02em |
| H1 | 48px | 500 | 1.1 | -0.02em |
| H2 | 32px | 500 | 1.2 | -0.01em |
| H3 | 24px | 500 | 1.3 | 0 |
| Body | 16px | 400 | 1.6 | 0 |
| Caption / Metadata | 12-14px | 400 | 1.4 | 0.02em |

**Quy tắc:**
- Không dùng quá 2 font.
- Headings không uppercase toàn bộ — chỉ metadata nhỏ mới uppercase.
- Sử dụng khoảng trắng (whitespace) làm yếu tố sang trọng.

### 2. Grid

- **12-column grid** cho desktop.
- **Container max-width:** 1280px.
- **Margin:** 64px desktop / 24px mobile.
- **Gutter:** 24px.
- **Alignment:** left-aligned text, images có thể full-bleed hoặc column-based.

### 3. Spacing System

```
4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128
```

- Section padding: 96-128px desktop.
- Between project blocks: 64-96px.
- Between image blocks: 16-24px.
- Between text + image: 32-48px.

### 4. Color

| Token | Hex | Usage |
|---|---|---|
| `--bg-primary` | `#FAFAF9` | Main background (warm off-white) |
| `--bg-secondary` | `#FFFFFF` | Cards / sections |
| `--text-primary` | `#1C1917` | Headings / body |
| `--text-secondary` | `#78716C` | Captions / metadata |
| `--text-muted` | `#A8A29E` | Subtle labels |
| `--border` | `#E7E5E4` | Dividers / hairlines |
| `--accent` | `#292524` | Buttons / links / hover |

**Lưu ý:** Không dùng màu thương hiệu của từng project làm màu chủ đạo.

### 5. Image System

- **Hero image:** full-width, full-bleed, max-height 80vh, object-fit cover.
- **Supporting images:** 2-col hoặc 3-col grid, 16-24px gap.
- **Mixed layout:** cho phép landscape/portrait/square cùng tồn tại, không ép cùng tỷ lệ.
- **Border radius:** 0px hoặc tối đa 4px.
- **Shadow:** rất nhẹ hoặc không shadow.
- **Caption:** caption nhỏ bên dưới, màu secondary.

## G. Page System

### 01 — COVER

- Full-viewport hero image (mờ nhẹ hoặc overlay gradient đen 10-20%).
- Team name "Artify Design" lớn, centered hoặc left-bottom.
- Tagline nhỏ: "Creative Studio · Ho Chi Minh City".
- Year: 2025 / 2026.
- Mũi tên hoặc text "Selected Works" dẫn xuống About/Works.
- Navigation minimal: About / Work / Team / Contact.

### 02 — ABOUT / CAPABILITIES

- Giới thiệu ngắn 2-3 câu về Artify Design.
- Grid capabilities: Branding, Key Visual, Social Media, POSM, Motion, Illustration.
- Mỗi capability: tên + mô tả 1 dòng.
- Có thể thêm số liệu tổng quan: 9 selected works, 4 designers, v.v. (không bịa số liệu không có).

### 03 — PROJECT COVER

Mỗi project detail bắt đầu bằng:
- Số thứ tự project (01-09).
- Project title lớn.
- Metadata: Designer / Category / Year.
- Client (chỉ nếu có thông tin xác nhận).
- Hero image full-width.

### 04 — PROJECT DETAIL

Cấu trúc nội dung mỗi project:
- **Concept** — 1-2 đoạn văn ngắn.
- **Visual System** — typography, color, style direction.
- **Application** — mockup, collateral, real-world usage.
- **Detail** — close-up, texture, supporting visuals.

Không viết quá dài; artwork là nhân vật chính.

### 05 — IMAGE GRID

Khi project có nhiều hình:
- 2 columns cho hình lớn.
- 3 columns cho detail shots.
- Full-width cho hero/mood shot.
- Mixed layout: kết hợp text column + image column.

### 06 — CONTACT / CLOSING

- Câu closing ngắn: "Let's create something meaningful together."
- Email contact.
- Social links (nếu user cung cấp).
- Footer: © Artify Design 2025.
